# Old version screenshots

Archived before images for Slipstream's UI comparison content, captured on
2026-10-23 using Playwright's Electron automation.

Source: the installed **Slipstream 0.1.0** app, whose executable is dated
2026-10-10. This installation predates the floating panels and consolidated chat
options menu. No new build was created to capture these images.

All images are unedited PNG captures of the app content at **1280 × 760**.

- [Overview](01-overview.png): start screen with the expanded favourites sidebar.
- [Live video and chat](02-live-with-chat.png): live playback with chat and expanded favourites.
- [Compact sidebar](03-compact-sidebar.png): live playback with favourites folded to avatars.
- [Appearance controls](04-appearance-controls.png): the original top-bar theme and accent menu.

The live channel, video, viewer counts, and chat are real content shown at capture
time. Capture metadata and the source app archive's SHA-256 are recorded in
[capture-info.json](capture-info.json).
